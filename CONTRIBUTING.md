# Contributing

This is a public release and documentation repository, not the Nomex Shift source repository. Nomex Shift is proprietary and is not accepting source-code pull requests through this repository.

You may:

- open a reproducible bug report;
- request a feature;
- propose corrections to public documentation; or
- privately report a vulnerability under [SECURITY.md](SECURITY.md).

Do not submit decompiled code, reverse-engineered material, modified installers, unofficial builds, extracted proprietary assets, secrets, personal data, or third-party material you lack permission to contribute. A documentation submission must be your own work and may be edited or declined. Submission does not grant permission to use Nomex code, branding, or artwork elsewhere.

By submitting documentation, you represent that you have the right to provide it and grant Nomex a perpetual, worldwide, non-exclusive right to use, reproduce, modify, and distribute that documentation as part of Nomex materials. If you do not agree, open an issue describing the correction instead of submitting a pull request.
