# Nomex Shift Support

Use the repository's issue chooser or **Support** inside Nomex Shift. Do not post license keys, complete diagnostic reports, credentials, or other private data in a public issue.

Before contacting support:

1. Record the exact Nomex Shift version and Windows version.
2. Note the adapter name, driver version, and concise error message.
3. Try **Refresh**, then **Restore Original** if a change failed.
4. Launch **Nomex Shift (Safe Mode)** for recovery if normal startup is unreliable.
5. Create a diagnostic report from **Settings → About**, preview it, and redact anything you do not want to share.

Never send license keys, passwords, tokens, seed phrases, private keys, signing certificates, or network passwords. Complete MAC addresses are normally unnecessary.

Use GitHub Issues only for reproducible public bugs and feature requests. Account, purchase, license, abuse, privacy, and security matters belong in private support.

Join the [official Nomex Discord](https://discord.gg/DcrzfkRTKK) for community support. Do not trust servers or direct messages claiming to be Nomex unless they are linked from an official Nomex surface.
