# Installation

## Before downloading

Use only the repository's [latest release](../../releases/latest) or another link published by Nomex. The official asset is named exactly `NomexShift-Setup.exe`. Releases also provide `SHA256SUMS.txt`.

## Install

1. Download both files from the same GitHub Release.
2. Verify the installer using [VERIFY_DOWNLOAD.md](VERIFY_DOWNLOAD.md).
3. Inspect **Properties → Digital Signatures** when a signed build is advertised.
4. Run `NomexShift-Setup.exe`.
5. Read and accept the EULA if you agree.
6. Approve administrator access only when Windows requests it for installation or adapter changes.
7. Complete first-run setup. No adapter is modified during the setup check.

## Upgrade

Download and run the newer official installer. The installer is designed to upgrade the installed product. Preserve settings when the installer offers that choice.

## Uninstall

Use **Settings → Apps → Installed apps → Nomex Shift → Uninstall**. Before removal, restore any adapter whose original identity you want Windows to use. Local settings may remain when preservation is selected.
